# 洛克小助手 · Free（RocoHelper Free）

洛克王国桌面助手 · 免费开源版。单机离线小工具合集，开箱即用：

- **丢球助手** — 普通丢球 / 轰炸机 / 自动技能，硬件级键鼠模拟，蓄力区间滑杆实时可调
- **挂机引擎** — 自动战斗闭环（等战斗 → 技能循环 → 低血丢球），战斗间隙巡逻找怪，异色全停保护
- **AI 陪玩** — 对局弹幕 / 情绪价值（**使用你自己的 API Key**，密钥只存本机，我们不碰你的 key）
- **视觉调试台** — ROI 标注工坊 / 模板管理 / OCR 预览（想折腾识别管线的进阶玩法）
- **背包盘点 / 工具箱 / 配置中心** — 网格识别快照、诊断小工具、全量配置可视化

> 本仓库**不包含**：PVP 对战全家桶、日常任务托管、抓包与协议解码、账号激活体系。
> 抓包/协议/授权相关代码**永不开源**，它们属于闭源的 Pro 版。
