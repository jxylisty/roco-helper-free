# 洛克小助手 · Free（RocoHelper Free）

洛克王国桌面辅助工具 · 免费开源版。单机离线硬核对战军师与小工具合集，开箱即用：

- ⚔️ **PVP 实时识别 & AI 军师** — 实时战况推演、战况雷达 HUD 浮窗、屏幕双方阵容顶栏、属性克制即时计算、本机赛季战报
- 🤖 **AI 陪玩 & 军师设置** — 支持填入你自己的 API Key（DeepSeek、智谱、OpenAI 等），密钥仅保存在本机，绝不上传
- 🛒 **远行商人** — 每日四时段货单速查 + 倒计时 + 本机货单历史（**免费专属功能**，网络聚合数据源）
- 📖 **精灵图鉴** — 全量 685+ 精灵图鉴、进化链、种族值与技能详细速查（官方公开 Wiki 数据）
- 🥚 **实用工具箱** — 属性克制计算器、蛋组反查、异色概率计算器、异色公母库存摆窝最优求解规划器
- 🪟 **桌面窗口体系** — 游戏窗口检测、无边框沉浸自绘标题栏、全局置顶、全局急停快捷键

> 💡 **关于功能边界**：
> 本仓库**不包含**：丢球助手、自动战斗挂机引擎、AI 对战自动驾驶接管、日常任务托管、背包 OCR 盘点与授权卡密体系。
> 自动化按键执行层在免费版中**物理抽壳**（仅保留无害存根或整文件缺席），上述自动化功能属于闭源的 **Pro 会员版**。

## 环境要求

- Windows 10 / 11
- Python 3.10+（推荐 Anaconda / uv）
- 洛克王国客户端（WeGame 启动）

## 快速开始

### 方式一：运行桌面客户端（推荐）
直接运行 `src-tauri/target/debug/lkwg-pvp-assistant.exe`（Tauri 原生桌面壳，自动拉起伴生后端）。

### 方式二：Python 源码启动
```bash
python server_main.py
```
控制台默认监听 `http://127.0.0.1:17366`，浏览器访问即可。
