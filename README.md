## 下载与运行

### 1. 下载

到本仓库右侧 **[Releases](../../releases)** 页面，下载最新版的 `洛克小助手Free.zip`。

> 暂未发布 Release 时，请加 QQ 群 `1109566147` 获取安装包。

### 2. 解压

把压缩包解压到一个**固定目录**（例如 `D:\洛克小助手\`）。

⚠️ 不要在压缩包内部直接双击运行，必须先完整解压。

### 3. 安装运行环境（一次性）

双击包内 `redist\环境安装.bat`，它会自动检测并安装：

| 检测项 | 缺了会怎样 |
| :--- | :--- |
| VC++ 运行库 | 主程序无法启动 |
| WebView2 运行时 | 界面空白（Win11 一般自带） |

### 4. 启动

双击 `洛克小助手Free\lkwg-pvp-assistant.exe`。

- 首次启动会拉起后端服务，黑窗口一闪而过属正常现象
- 启动后进入 **体检页**，确认「运行时依赖」为绿色
- 后端固定监听 `http://127.0.0.1:17366`

## 常见问题

| 现象 | 处理 |
| :--- | :--- |
| 杀软 / SmartScreen 弹警告 | 点「更多信息 → 仍要运行」 |
| 双击没反应 | 右键「以管理员身份运行」 |
| 界面空白 | 缺 WebView2 运行时，重跑 `环境安装.bat` |
| 游戏窗口识别不到 | 游戏不要最小化；建议 1920×1080 及以上 |
