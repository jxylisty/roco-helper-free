# 免费 / 付费 功能拆分（权威清单）

> 本文件是两个版本功能边界的唯一权威来源。改边界先改这里，再动代码。

## 三条原则

1. **免费版 = 体验引流与硬核工具。** 开放 PVP 实时识别、AI 军师与全量查询工具箱，让玩家单机离线即可流畅体验核心辅助。
2. **付费卖的是自动化与省心服务。** 丢球助手、挂机引擎、日常任务一键托管、AI 对战自动驾驶接管等按键自动化全部属于 Pro 版。破解者拿到 Free 包是物理抽壳的，执行层代码物理不入树，改闸门也变不出按键代码。
3. **三类敏感代码永不进本仓库**：授权体系（服务端与客户端机器码校验）/ 拟人按键驱动与自动化执行层 / 密钥与加固构建链。

## 免费版（本仓库开源）

| 模块 | 内容与说明 |
|---|---|
| **PVP 实时识别 & AI 军师** | 实时战况推演、战况浮窗（雷达 HUD）、双方阵容顶栏、克制推算、赛季战报（本机数据） |
| **AI 设置** | 用户自带 API Key（DeepSeek/智谱等），密钥只存本机，支持对局弹幕与军师建议 |
| **远行商人** | **免费专属**：每日四时段货单速查 + 倒计时 + 本机历史记录（爬取免费聚合页，由 sync_free.py 注入） |
| **精灵图鉴** | 全量 685+ 精灵图鉴、进化链、种族值与技能速查（官方公开 Wiki 数据） |
| **属性克制计算器** | 18 系克制速查、双克/双抗多倍率计算 |
| **蛋组与孵蛋工具** | 蛋组查询、7 大渠道异色概率计算器、异色摆窝规划器（后台求解最优配对） |
| **窗口与快捷键体系** | 悬浮窗、屏幕置顶、窗口停靠、急停快捷键等基础框架 |

## 永不开源清单（任何情况下不进本仓库）

- `server/`（worker.js 等） — 授权服务端与鉴权 API
- `src/gui/auth*.py`、`auth_core.pyd` — 客户端机器码与卡密校验核心
- `src/driver/human_input.py` — 拟人化鼠标键盘按键规划与驱动执行层
- `auto_throw_ball.py`（真实执行版）、`src/states/battle_engine.py` — 自动化丢球与挂机引擎实现
- `src/gui/ai_autopilot.py` — AI 对战自动接管执行器
- `src/tasks/` — 日常任务执行模块
- `src/perception/bag_scanner.py`、`ball_watcher.py` — 背包与槽位监视执行层
- `keys.json`、`tools/build_hardened.py`、`tools/gen_worker_keys.js` — 一切密钥与加固构建链
