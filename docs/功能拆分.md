# 免费 / 付费 功能拆分（权威清单）

> 本文件是两个版本功能边界的唯一权威来源。改边界先改这里，再动代码。

## 三条原则

1. **免费版 = 单机离线可完整体验。** 破解者拿到 Free 包是物理残缺的，付费功能代码不在包里，无可破解。
2. **付费卖的不是二进制锁，是服务。** PVP 全家桶 + 日常托管 + 持续更新 + 会员群，破解包拿不到这些。
3. **三类代码永不进本仓库**：抓包与协议解码 / 授权体系 / 密钥与构建链。

## 免费版（本仓库，MIT 开源）

| 模块 | 内容 |
|---|---|
| 丢球助手 | 普通丢球 / 轰炸机 / 自动技能，滑杆蓄力区间 |
| 挂机引擎 | 自动战斗闭环、巡逻找怪、脱困、异色全停 |
| AI 设置 / AI 陪玩 | 用户自带 API Key，密钥只存本机 |
| 视觉调试台 | ROI 工坊、模板管理、OCR 预览、实时识别 |
| 背包盘点 | 咕噜球网格识别与快照对比 |
| 工具箱 / 配置中心 | 诊断小工具、全量配置可视化编辑 |
| 窗口体系 | 悬浮窗、置顶、快捷键、标题栏 |

## Pro 版（闭源，付费群分发）

| 模块 | 内容 |
|---|---|
| PVP 对战全家桶 | 实时识别（OCR）、伤害推演、AI 对战、赛季战报与 ELO |
| 日常任务 | MAA 式托管、花种挑战、预约挂机 |
| 持续更新 | 更新通道只在 Pro |
| 群服务 | 会员群、福利、抽奖、技术支持 |

## 永不开源清单（任何情况下不进本仓库）

- `src/capture/`、`tools/pvp_packet_capture.py` 等 — 抓包与协议解码（rkpp）
- `server/`（worker.js 等） — 授权服务端
- `src/gui/auth*.py`、`auth_core.pyd` — 授权客户端与机器码校验
- `src/pvp/seadata*` 及加密数据分发链 — 数据密钥种子体系
- `keys.json`、`build/_hardened/`、`tools/build_hardened.py`、`tools/gen_worker_keys.js` — 一切密钥与构建链
