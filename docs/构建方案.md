# 免费版构建方案（双仓分流）

> 状态：**v0.4 已落地**。`python tools/sync_free.py --main <主仓> --out dist_free`
> 可一键产出免费树；功能边界以 `docs/功能拆分.md` 为唯一权威。
> 免费(噱头) = PVP 识别引擎 + AI 军师悬浮窗 + AI 设置 + 赛季战报(本机) + 图鉴；
> 付费(锁页) = 丢球助手/挂机引擎 + AI 对战(接管/MCP) + 日常任务；
> 执行层(auto_throw_ball/battle_engine/human_input 等)物理不入树, 以存根顶替。

## 核心思路：一个代码库，两个构建产物

主仓（`auto-rocoassit-helper`，闭源）是唯一代码源。`tools/sync_free.py`
按清单从主仓生成 Free 树：

```
主仓代码 ──copy(排除清单)──> Free 树 ──stub(付费模块)──> 免费版包
                                                    └─> 更新通道 = 本仓库
免费专属模块 ──tools/free_inject/ 注入──> Free 树(主仓同步注入实现)
```

付费模块在 Free 树中是**同名空实现存根**（保持类名兼容），主仓代码零改动，
双仓维护成本最低。

**免费专属模块注入通道**（`tools/free_inject/`，2026-10-01 起）：
远行商人等免费专属功能的源文件与接线补丁都放在本仓 `tools/free_inject/`，
由 `apply_inject_files` + `apply_inject_patches` 注入产物树。
前端接线（工具箱功能入口卡 / 页面 section / 路由别名）已收进主仓原生代码，
免费树随拷贝继承，无需补丁；bridge.py 三处接线补丁保留（幂等）。
归属约定：**免费版实现以 free_inject 为权威**；主仓 `src/gui/bridge_merchant.py`
等文件是交接快照，付费版可自行演进，但每次演进后需回移 free_inject
（否则下次 sync 会用 free_inject 版本覆盖免费树）。
新增免费功能的固定姿势（主仓一次改齐、免费树自动继承）：
`app.js` TOOL_PAGE_CARDS 加一条功能入口卡 + 独立 section + 后端 Mixin。

## 三个必须处理的坑

1. **自动更新必须分流（最大的坑）**
   Pro 的更新器从主仓拉更新。Free 用户若沿用同一通道，会"更新着更新着
   变成完整版"。Free 构建的更新源必须指向本仓库，构建时校验更新 URL。
2. **存根而非删除**
   `bridge.py` 按类名挂载 Mix-in。Free 树提供同名空实现
   （PvpEngineMixin / PvpDataMixin / DailyMixin / AuthUpdateMixin），
   保持 import 链完整。
3. **数据层不打包**
   Free 构建不带精灵/技能数据库与加密链（`src/pvp/`、seadata、.bin）。
   丢球与挂机不依赖图鉴数据，正好与拆分对齐。

## 分发加固（2026-11-09 起）— 核心算法不再明文分发

背景：免费包此前是纯明文分发（`sync_free.py` 排除 `*.pyd` 防主仓编译产物混入），
付费执行层虽已物理抽壳，但伤害公式与 RKPP 协议层/解码器仍以明文 `.py` 随包走。

`tools/compile_free_pyd.py` 在 **sync → 装内嵌 python → ★编译加固 → 组装打 zip**
的流水线里对最终发布树做原地 Cython 编译，清单与主仓 `build_release.py`
批1（纯算法 7 模块）+ 批2（协议层 14 模块）完全一致：

```bash
python tools/compile_free_pyd.py --free-root <发布树根>   # 树需已含 python/
```

- 编译解释器用主仓 `.venv-build`（Python 3.12 + Cython），产物 cp312 ABI，
  与包内嵌 Python 3.12.x 兼容；脚本会用内嵌 `python.exe` 实导每个 `.pyd` 验证。
- `rkpp_live_tools.py` 保留明文（解码器独立进程脚本入口，python 无法直接执行 .pyd）。
- 必须继承主仓两个踩坑约定：`annotation_typing=False`（否则 rkpp_analyzer
  的 set 端口参数运行时 TypeError，抓包全灭）；vcvars 先 cd 再相对名 call。
- 脚本自带冒烟：17366 起服务，`auth_status` 用户模式、`toggle_normal` 闸门拦截。
- 幂等：已是 .pyd-only 形态时跳过编译，只做校验。
