免费版帮助与教程

入群验证、对战识别和离线图鉴的使用说明

快速上手
  1. 先逛工具箱 — 图鉴、属性克制、蛋组互查和异色繁育等离线工具，解压后即可使用。
  2. 免费入群验证 — 要用 PVP 识别或远行商人，点击左上角头像，输入 QQ 号和群公告里的口令。不用注册账号、购买会员或输入卡密。
  3. 开启对战识别 — 通过 WeGame 进入游戏，再到「PVP 对战」开启识别。进入一场对战后，助手才能收到对战数据。
  4. 查看伤害和建议 — 可使用伤害预览、战况悬浮窗和 AI 军师。使用 AI 军师前，请在 AI 设置中配置自己的服务和 Key；建议只供参考，不会替你出招。
常见问题
群验证失败或过期怎么办？
口令不正确时，请核对群公告；验证过期时，用当前口令重新验证；如果提示版本过期，请到群里下载新包。连接失败时检查网络后再试，不要把口令或验证码截图发给别人。
图鉴要联网同步吗？
不用。图鉴随赛季安装包更新，平时可离线查询，不需要图鉴 Key。体检若提示某份核心数据缺失或无法读取，请重新完整解压当前赛季包。
体检有黄灯，或者识别一直等数据？
没开游戏时，「游戏窗口」和「实时数据通道」显示等待是正常的。如果已经进入对战，先确认完成了入群验证并已开启 PVP 识别，再重新检测。只查图鉴不用等这些项目变绿。
为什么找不到自动代打或 MCP 自玩？
免费版只提供识别、伤害查看和军师建议，不包含 MCP 自玩、自动出招、排位连打、丢球或挂机执行功能。
免费版能看赛季战报和对局复盘吗？
赛季战报、ELO 分析和历史复盘是付费版功能。免费版仍可查看当前对战、伤害预览和军师建议。
双击后打不开，或一直转圈？
请确认已完整解压，不要从 ZIP 内直接启动。退出旧版助手后重新打开；如果仍失败，请按包内安装说明检查运行环境。
反馈时请附上版本号、出问题的页面和体检截图；请遮掉 QQ 号、群口令和 API Key。
